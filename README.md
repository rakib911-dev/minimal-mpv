## Locations

<pre>
Linux:   ~/.config/mpv/
Windows: C:/Users/%username%/AppData/Roaming/mpv/
macOS:   ~/Library/Application Support/mpv/
</pre>

## Folder Structure

<pre>
mpv/
├── input.conf
├── mpv.conf
└── scripts/
    └── minibar.lua
</pre>

## Keybinds

<pre>
Space         Play / Pause
Right / Left  Seek forward / backward 10s
f             Toggle fullscreen
z             Toggle fill
</pre>
